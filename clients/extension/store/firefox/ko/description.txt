Bramble은 사용자의 비밀을 자신의 기기에서만 보관하는 무료 오픈 소스 비밀번호 관리자입니다. 계정도, 볼트를 맡겨야 할 회사 서버도, 침해되어 모든 것을 유출시킬 중앙 데이터베이스도 없습니다. 볼트는 사용자가, 비밀번호는 사용자가 보관합니다. 그게 전부입니다.

Firefox, LibreWolf, Waterfox, Zen 및 기타 Firefox 기반 브라우저에서 작동합니다. 설치하면 약 1분 안에 사용을 시작할 수 있습니다. Bramble은 macOS, Windows, Linux, iOS, Android용 앱도 제공하며, 볼트는 모든 기기 간에 동기화됩니다.

하는 일

비밀번호는 사용자의 기기에서 암호화되어 브라우저 자체 확장 프로그램 저장소에 보관됩니다. 한 번만 설정하면 바로 로그인 자동 완성, 새 비밀번호 저장, 비밀번호 생성이 시작됩니다.

기기가 두 대 이상입니까? 기기를 페어링하면 Bramble이 볼트를 기기 간에 직접, 종단 간 암호화로 동기화합니다. 기기를 연결해 주는 릴레이는 암호문만 볼 수 있고 아무것도 저장하지 않으므로, 읽을 수 있는 어떤 정보도 다른 사람의 서버에 남지 않습니다.

기능

- 항상 로컬 우선. 암호화된 볼트는 사용자의 기기, 브라우저 저장소에만 있습니다. 계정이 없으며, 사용자가 선택한 저장소에 백업하지 않는 한 다른 곳에는 사본이 없습니다.
- P2P 동기화. 종단 간 암호화된 연결을 통해 기기들이 항목별로 병합되며 동기화 상태를 유지합니다. 기기를 연결하는 릴레이는 암호문만 볼 수 있고 아무것도 저장하지 않습니다.
- 강력한 암호화. 키에는 Argon2id, 데이터에는 AES-256-GCM, 항목마다 고유 키를 갖는 봉투 암호화를 적용합니다. 비밀 정보는 사용 후 메모리에서 지워집니다.
- 모든 항목 암호화. 사이트 이름, 사용자 이름, 메모 등 모든 것이 암호화됩니다.
- 도메인 인식 자동 완성. www.example.com, ca.accounts.example.com, example.com이 모두 하나의 로그인 정보와 일치합니다. 페이지 내 드롭다운은 iframe과 섀도 DOM 안의 양식에도 접근합니다.
- 패스키. Bramble은 사용자 자신의 패스키 인증자 역할을 합니다. 패스키를 만들고 로그인할 수 있으며, 볼트에 저장되고 다른 항목처럼 동기화됩니다.
- 로그인 정보 외에도. 로그인 정보, 결제 카드, 보안 메모, SSH 키를 각각의 전용 필드로 보관할 수 있습니다.
- 이메일 별칭. Addy.io, SimpleLogin, Fastmail 또는 직접 소유한 도메인을 통해 사이트마다 고유한 전달 주소를 받을 수 있습니다. 가입 양식에서 바로 제공됩니다.
- 탭하여 잠금 해제. 마스터 비밀번호와 함께 Touch ID 또는 Windows Hello를 사용하거나, 이 방법만으로 잠금 해제하도록 설정할 수 있습니다.
- 복구 코드. 모든 볼트는 설정 시 보안 복구 코드를 받습니다. 마스터 비밀번호와 별개로 볼트를 잠금 해제할 수 있는 인쇄 가능한 백업입니다.
- TOTP / 2FA 코드. otpauth:// URI 또는 비밀 키를 붙여 넣으면 Bramble이 코드를 생성합니다.
- 암호화된 백업. 언제든지 볼트를 암호화된 파일로 내보내거나, Dropbox, S3 호환 버킷, WebDAV로 암호화된 백업을 예약할 수 있습니다. 제공업체는 암호문만 볼 수 있습니다.
- 종속 없음. 원할 때 언제든지 표준 KeePass(.kdbx) 파일로 내보낼 수 있습니다.
- 여러 볼트. 각각 고유한 마스터 비밀번호로 보호되는 별도의 볼트를 나란히 유지할 수 있습니다.
- 내장 비밀번호 생성기.
- 선택적 유출 확인. k-익명성을 사용한 Have I Been Pwned 조회: 비밀번호 해시의 짧은 접두어만 전송되며 비밀번호 자체는 절대 전송되지 않습니다. 기본값은 꺼짐입니다.
- 15분 동안 사용하지 않으면 자동 잠금(구성 가능).
- 1Password, Bitwarden, Proton Pass, LastPass, Dashlane, Enpass, AliasVault, RoboForm, KeePass, Firefox, Apple Passwords, Google Password Manager에서 가져오기.

로컬 우선인 이유

클라우드 관리자는 모든 사용자의 볼트를 자사 서버에 보관하므로 서버가 하나의 거대한 표적이 됩니다. 침해가 발생하면 볼트 하나가 아니라 수백만 개가 동시에 유출되며, 그 사실은 흔히 몇 달 뒤에야 공개됩니다.

Bramble은 이 방식을 뒤집습니다.

- 침해될 중앙 볼트 더미가 없습니다. 볼트는 암호화되지 않은 상태로 기기를 떠나지 않습니다.
- 계정도, 구독도, 광고도, 원격 측정도 없습니다. 가입할 것이 없습니다.
- 데이터도, 기기도 사용자의 것입니다. 여러분의 기기 간에 동기화하거나, 한 기기에만 보관하거나, 직접 선택한 저장소에 암호화해 백업할 수 있습니다. 읽을 수 있는 어떤 정보도 다른 사람의 서버에 보관되지 않습니다.
- 신뢰할 것은 코드뿐입니다. Bramble은 GPL에 따라 오픈 소스이며 코드는 GitHub에 공개되어 있습니다.

암호화 작동 방식

Bramble은 LUKS 방식의 키 슬롯과 봉투 암호화를 사용합니다. 하나의 무작위 볼트 키가 데이터를 보호합니다. 각 잠금 해제 방법(마스터 비밀번호, Touch ID 또는 Windows Hello, 복구 코드)은 동일한 볼트 키의 사본을 풀어내는 고유한 키 암호화 키를 파생합니다. 따라서 잠금 해제 방법을 추가하거나 철회해도 어떤 항목도 다시 암호화되지 않습니다. 그런 다음 볼트 키가 항목마다 새로운 항목별 키를 풀어냅니다. 모든 것은 AES-256-GCM입니다.

KeePass에서 넘어오셨나요?

익숙하게 느껴지실 것입니다. 암호화된 볼트, 사용자의 통제권, 그리고 타인의 서버가 필요하지 않습니다. Bramble은 KDBX4 파일(키 파일 포함)을 가져오고, 원할 때마다 .kdbx로 다시 내보낼 수 있습니다. 차이점은 자동 완성이 내장되어 있어 도메인 일치와 페이지 내 드롭다운이 기본 제공되므로 플러그인 브리지가 없어도 되고, 기기 간 동기화도 내장되어 있으며, 여러 플러그인 대신 Argon2id와 AES-256-GCM을 사용하는 현대적인 단일 빌드로 제공된다는 점입니다. 깔끔한 UI에 다크 모드도 포함되어 있습니다.
