Bramble ist ein kostenloser Open-Source-Passwortmanager, der Ihre Geheimnisse auf Ihren eigenen Geräten aufbewahrt. Kein Konto, kein Unternehmensserver, dem Sie Ihren Tresor anvertrauen müssen, und keine zentrale Datenbank, die gehackt werden und alles preisgeben kann. Sie haben den Tresor, Sie haben das Passwort, das ist alles.

Läuft in Chrome, Edge, Brave, Arc und anderen Chromium-Browsern. Installieren Sie die Erweiterung, und in etwa einer Minute sind Sie startklar. Bramble bietet außerdem Apps für macOS, Windows, Linux, iOS und Android, und Ihr Tresor wird zwischen allen Geräten synchronisiert.

DAS LEISTET BRAMBLE

Ihre Passwörter werden auf Ihrem Gerät verschlüsselt und im privaten Speicher des Browsers aufbewahrt. Einmal eingerichtet, füllen Sie Logins automatisch aus, speichern neue und generieren sofort Passwörter.

Haben Sie mehr als ein Gerät? Koppeln Sie sie, und Bramble gleicht Ihren Tresor direkt zwischen ihnen ab – Ende-zu-Ende-verschlüsselt. Das Relay, das Ihre Geräte zusammenführt, sieht ausschließlich verschlüsselte Daten und speichert nichts, sodass niemals lesbare Daten auf einem fremden Server landen.

FUNKTIONEN

- Local-first, immer. Ihr verschlüsselter Tresor bleibt auf Ihrem Gerät, im privaten Speicher des Browsers. Kein Konto und keine Kopie an anderer Stelle, es sei denn, Sie sichern ihn auf einem Speicherort Ihrer Wahl.
- Peer-to-Peer-Sync. Ihre Geräte bleiben über eine Ende-zu-Ende-verschlüsselte Verbindung synchron, Eintrag für Eintrag zusammengeführt. Das Relay, das sie verbindet, sieht ausschließlich verschlüsselte Daten und speichert nichts.
- Professionelle Kryptografie. Argon2id für Ihren Schlüssel, AES-256-GCM für Daten, Umschlagverschlüsselung, sodass jeder Eintrag einen eigenen Schlüssel hat. Geheimnisse werden nach der Verwendung aus dem Speicher gelöscht.
- Alles verschlüsselt. Websitenamen, Benutzernamen, Notizen – einfach alles.
- Domain-intelligentes Autofill. www.example.com, ca.accounts.example.com und example.com passen alle zu einem Login. Das Dropdown auf der Seite erreicht Formulare in iframes und im Shadow DOM.
- Passkeys. Bramble ist Ihr eigener Passkey-Authenticator: Erstellen Sie Passkeys und melden Sie sich damit an; sie werden in Ihrem Tresor gespeichert und wie alles andere synchronisiert.
- Mehr als nur Logins. Logins, Zahlungskarten, sichere Notizen und SSH-Schlüssel, jeweils mit eigenen Feldern.
- E-Mail-Aliasse. Erhalten Sie für jede Website eine eindeutige Weiterleitungsadresse über Addy.io, SimpleLogin oder Fastmail oder über eine eigene Domain, direkt im Anmeldeformular angeboten.
- Entsperren per Tipp. Registrieren Sie einen YubiKey, Touch ID oder Windows Hello und entsperren Sie per Tipp über WebAuthn PRF. Verwenden Sie diese Methode zusammen mit Ihrem Master-Passwort oder machen Sie sie zu Ihrem einzigen Zugang.
- Wiederherstellungscodes. Jeder Tresor erhält bei der Einrichtung einen sicheren Wiederherstellungscode: ein druckbares Backup, das ihn unabhängig von Ihrem Master-Passwort entsperrt.
- TOTP-/2FA-Codes. Fügen Sie eine otpauth://-URI oder ein Secret ein, und Bramble generiert die Codes.
- Verschlüsselte Backups. Exportieren Sie Ihren Tresor jederzeit in eine verschlüsselte Datei oder planen Sie verschlüsselte Backups zu Dropbox, in einen S3-kompatiblen Bucket oder zu WebDAV. Der Anbieter sieht ausschließlich verschlüsselte Daten.
- Kein Lock-in. Exportieren Sie in eine Standard-KeePass-Datei (.kdbx), wann immer Sie wechseln möchten.
- Mehrere Tresore. Halten Sie getrennte Tresore nebeneinander, jeden mit einem eigenen Master-Passwort.
- Integrierter Passwortgenerator.
- Optionale Leck-Prüfung. Abfrage bei Have I Been Pwned mit k-Anonymität: Es wird nur ein kurzes Präfix des Passwort-Hashes gesendet, niemals das Passwort. Standardmäßig deaktiviert.
- Automatische Sperre nach 15 Minuten Inaktivität (konfigurierbar).
- Einfacher Wechsel. Importieren Sie aus anderen Passwortmanagern oder aus einer KeePass-Datei.

WARUM LOCAL-FIRST

Cloud-Manager legen die Tresore aller Nutzer auf ihren Servern ab – ein einziges großes Ziel. Kommt es zu einem Hack, sind nicht nur ein Tresor betroffen, sondern Millionen auf einmal, oft erst Monate später bekannt gegeben.

Bramble dreht das um:

- Kein zentraler Haufen von Tresoren, der gehackt werden kann. Ihr Tresor verlässt Ihre Geräte niemals unverschlüsselt.
- Kein Konto, kein Abo, keine Werbung, keine Telemetrie. Nichts, wofür Sie sich anmelden müssen.
- Ihre Daten, Ihre Geräte. Synchronisieren Sie sie über Ihre eigenen Geräte, behalten Sie sie auf einem Rechner oder sichern Sie sie verschlüsselt an einem Speicherort Ihrer Wahl. Niemals liegen lesbare Daten auf dem Server eines anderen.
- Nichts, dem Sie außer dem Code vertrauen müssen. Bramble ist Open Source unter der GPL, und der Code ist öffentlich auf GitHub.

SO FUNKTIONIERT DIE VERSCHLÜSSELUNG

Bramble verwendet LUKS-artige Schlüssel-Slots und Umschlagverschlüsselung. Ein zufälliger Vault Key schützt Ihre Daten. Jede Entsperrmethode (Master-Passwort, Sicherheitsschlüssel, Wiederherstellungscode) leitet ihren eigenen Key-Encryption-Key ab, der eine Kopie desselben Vault Key entpackt, sodass das Hinzufügen oder Widerrufen einer Entsperrmethode niemals einen einzelnen Eintrag neu verschlüsselt. Der Vault Key entpackt dann für jeden Eintrag einen frischen, eintragsspezifischen Schlüssel. Alles ist AES-256-GCM.

KOMMEN SIE VON KEEPASS?

Sie werden sich wie zu Hause fühlen: Ihr verschlüsselter Tresor, Ihre Kontrolle und kein fremder Server nötig. Bramble importiert Ihre KDBX4-Dateien (einschließlich Schlüsseldateien) und exportiert jederzeit zurück nach .kdbx, wann immer Sie möchten. Die Unterschiede: Autofill ist integriert, mit Domain-Abgleich und einem Dropdown auf der Seite, sodass keine Plugin-Brücke nötig ist; die Synchronisierung zwischen Ihren Geräten ist ebenfalls integriert; und es gibt einen modernen Build mit Argon2id und AES-256-GCM statt einer Vielzahl von Plugins. Saubere Benutzeroberfläche, inklusive Dark Mode.
